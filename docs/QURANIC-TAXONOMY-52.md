# Quranic Taxonomy v2.0 — Sprint 52 Expansion

**Date:** November 11, 2026  
**Sprint:** 52  
**Status:** Implemented  
**Previous Version:** Quranic Taxonomy v1.0 (Sprint 35)

## Overview

This document describes the expanded Quranic taxonomy implemented in Sprint 52. The taxonomy organizes Quranic guidance into three layers:

1. **Dimensions** (15) — Broad areas of human life and Quranic guidance
2. **Domains** (14) — Organizational categories (proposals, not approved taxonomy)
3. **Topics** (18) — Curated Quranic subjects with explicit ayah relationships

## Dimensions (15)

Dimensions are topic-level navigation aids. Each dimension groups related topics and provides a lens for exploring the Quran.

### Original 10 Dimensions (Sprint 8)

1. **Spiritual** (روحاني) — Allah, Ibadah, Tawakkul, Akhirah
2. **Personal** (شخصي) — Mental health, self-development, emotions
3. **Family** (أسري) — Marriage, parenting, divorce, rights
4. **Social** (اجتماعي) — Community, justice, rights, responsibilities
5. **Economic** (اقتصادي) — Wealth, trade, charity, economic justice
6. **Intellectual** (فكري) — Knowledge, wisdom, reflection, learning
7. **Governance** (حكم) — Leadership, justice, consultation, responsibility
8. **Jihad** (جهاد) — Struggle, effort, striving in the way of Allah
9. **Interfaith** (تعددي) — Other religions, dialogue, common ground
10. **Ilm (Knowledge)** (علم) — All knowledge as Allah's signs

### New 5 Dimensions (Sprint 52)

11. **Worship and Devotion** (عبادة) — Prescribed acts: prayer, fasting, pilgrimage, supplication
12. **Prophets and Their Stories** (الأنبياء) — Prophetic narratives and historical lessons
13. **Creation and Signs in Nature** (الخلق) — Natural world as signs of the Creator
14. **The Hereafter and Resurrection** (الآخرة) — Eschatology: judgment, paradise, hell
15. **Law and Legal Obligations** (الأحكام) — Halal/haram, obligations, prohibitions

### Dimension Expansion Rationale

Each new dimension addresses a genuine coverage gap:

- **Worship** — Distinct from spiritual (outward practice vs. inner relationship)
- **Prophets** — Distinct from history (focused on prophetic narratives)
- **Creation** — Distinct from knowledge (focused on natural world as signs)
- **Hereafter** — Distinct from spiritual (eschatology vs. present-life faith)
- **Law** — Distinct from governance (specific rulings vs. leadership/justice)

### Topic Data Model

Each topic includes:

```typescript
interface Topic {
  slug: string;              // Stable URL-safe identifier
  title: string;             // English title
  arabicTitle: string;       // Verified Arabic title
  summary: string;           // Short description
  relations: TopicRelation[]; // Curated ayah relationships
  related: string[];         // Related topic slugs
  provenance: ProvenanceRecord;
}

interface TopicRelation {
  ref: AyahRef;              // surahNumber:ayahNumber
  type: RelationType;        // LEXICAL_MATCH, TOPIC_ASSOCIATION, etc.
  rationale: string;         // Neutral description of inclusion
  provenance?: ProvenanceRecord; // Optional per-relation override
}

interface ProvenanceRecord {
  method: string;            // How selection was produced
  curator: string;           // Who produced it
  reviewedAt: string;        // ISO date
  status: ReviewStatus;      // "pending-scholarly-review" | "editorial-approved"
}
```

### Topic Expansion Rationale

Each new topic addresses a distinct Quranic subject:

- **Tawheed** — Foundational theological concept, distinct from general belief
- **Prayer** — Central act of worship, distinct from general devotion
- **Supplication** — Personal communication with God, distinct from formal prayer
- **God-Consciousness** — Ethical and spiritual awareness, distinct from general ethics
- **Repentance** — Spiritual return and renewal, distinct from forgiveness
- **Prophets** — Narrative guidance, distinct from general history
- **Good Character** — Ethical conduct, distinct from general ethics

## Knowledge Graph

The knowledge graph represents the taxonomy as a graph structure:

- **Nodes:** 33 (15 dimensions + 18 topics)
- **Edges:** Dimension-topic mappings + topic-topic relationships
- **Status:** All nodes carry `pending-scholarly-review`

The graph is used for:
- Navigation (dimension → topic → related topics)
- Discovery (finding related content)
- Validation (ensuring all references resolve)

## Constraints

- All existing dimension/domain/topic IDs and slugs preserved
- No modification to Quran text, translations, Tafsir, or morphology
- No AI-generated religious content
- All content carries `pending-scholarly-review` status
- Root occurrence data remains independent from thematic classifications
